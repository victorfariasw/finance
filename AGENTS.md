# Expo SDK 54

Este projeto usa **Expo SDK 54** (React Native 0.81, React 19.1) para ser compatível com o
app **Expo Go** do dono (que suporta SDK 54). NÃO faça upgrade de SDK sem confirmar que o
Expo Go instalado no celular suporta a nova versão — senão dá "Project is incompatible with
this version of Expo Go".

Docs versionadas: https://docs.expo.dev/versions/v54.0.0/
